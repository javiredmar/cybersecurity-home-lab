# 🛡️ Cybersecurity Home Lab

Repositorio personal de laboratorios prácticos, análisis forense, seguridad de redes y monitorización SOC realizados durante mi preparación para la certificación **CompTIA Security+ (SY0-701)**.

## 🖥️ Entorno de Virtualización
* **Host:** Windows 10
* **Hipervisor:** Oracle VirtualBox
* **Máquinas Virtuales:** Kali Linux, Windows 10 (Cliente/Endpoint)
